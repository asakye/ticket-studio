## 怎么收钱（变现闭环）

产品的收费逻辑已经做好：**免费版 2 款模板 + 导出带小水印；付费 6 元一次买断，解锁全部 3 款高级模板 + 3 倍高清无水印导出**。用户付费状态存在浏览器本地，换设备可用解锁码恢复。

你要做的只有两步：

1. **放收款码**：把自己的微信/支付宝收款码保存为 `assets/pay-qr.png`（任意一张就行），页面上会自动显示，用户扫码付款。
2. **发解锁码**：用户付款后，把 `js/config.js` 里 `licenseCodes` 中的解锁码（现在有一个 `TICKET-2026-FIRST`）发给对方，对方输入后永久解锁。

想改价格、加解锁码、换水印文字，都只改 `js/config.js`：

```js
window.TT_CONFIG = {
  proPrice: "6",              // 显示价格
  watermarkText: "Made with 票根工坊",
  licenseCodes: ["TICKET-2026-FIRST"],  // 解锁码，逗号分隔可加多个
};
```

## 怎么推广（决定收入的关键）

产品做得快，难的是让人知道。这套打法已经被验证过（V2EX 真实案例：靠发抖音从日活 40 冲到 6000）：

1. **抖音/小红书每天 1 条**：用自己生成的票根当素材，文案写「30 秒把旅行照变成一张票根」，带上 `#票根工坊` 标签。
2. **朋友圈裂变**：每次旅行后发九宫格 + 票根，朋友问「怎么做的」→ 回复链接。
3. **景点/旅行攻略评论区**：自然分享工具（别硬广，选「照片怎么发更有仪式感」相关话题）。
4. **微信群/社区**：旅行群、摄影群、大学生群里免费送解锁码换口碑。
5. **SEO**：页面标题和描述已优化「旅行票根生成器」等关键词，上线后提交百度/谷歌站长平台。

## 已经内置的细节

- 手机端可「添加到主屏幕」：PWA 支持，体验接近原生 App，绕开 App Store 审核。
- 离线可用：Service Worker 缓存了全部静态资源。
- 隐私卖点：所有图片只在本地处理，不上传服务器——这是竞品很难抄的信任点。
- 演示模式：`?demo` 参数会自动加载示例图，方便给别人演示或截图。
